Gemini API Key Configuration

To generate voice audio, this project requires a Google Gemini API Key. You can get one 100% free from Google AI Studio.

Option 1: Paste Key Directly in UI (Instant)

Paste your key here to start generating audio right away in this session:

Option 2: Add in .env file (Permanent)

Open the project's .env file and add your key:

GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE

Once saved in .env, it will be automatically loaded on server start!

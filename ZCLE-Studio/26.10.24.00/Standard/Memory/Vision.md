## 1. What is ZCLE Studio?

**ZCLE Studio** (**Zero-Friction Cinematic Learning Engine Studio**) is an autonomous programmatic video generation platform that produces **3Blue1Brown-quality educational and technical explainer videos** from structured input.

The user's vision is crystal clear:
> Videos must look like authentic 3Blue1Brown mathematical and scientific explainers (as seen in Grant Sanderson's videos, e.g., *Large Language Models Explained Briefly*), where **every visual geometry is authentic to the topic** (not copy-paste templates) and **audio narration and visual animations are 100% in lockstep synchronization (0-second drift)**.

---

## 2. The Core Problem Solved

- **The Fallacy of Rigid Card Templates:** In earlier iterations, topics like Black Hole or GPU were forced into generic rounded rectangle cards and probability bar charts where only text changed. The user rightfully rejected this: a Black Hole video must show spacetime warping, geodesic light rays, and event horizons; a CPU video must show silicon logic gates and clock square waves.
- **The Sync Problem:** Animations must not float loosely over background speech. When the speaker utters a concept or noun at second `07.42`, the corresponding geometric transformation must execute at that exact millisecond.
- **The Data-Driven Truth:** No chart, 3D box, rotation, or curve can exist without underlying numerical data (e.g., mass $M$, radius $R_s$, curvature depth $z$, probability floats $0.63$).

---

## 3. The Approved 2-File Architecture

ZCLE Studio operates on a clean separation of concerns using two complementary input files:

```
┌───────────────────────────────────────────────────────────────────────┐
│                      THE 2-FILE INPUT SYSTEM                          │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  [FILE 1: Narration Script (.txt / .md)]                              │
│  The complete spoken explanation text of the topic / chapter.         │
│  Converted into voice audio (Edge-TTS) with millisecond timestamps.   │
│                                                                       │
│  [FILE 2: AI Director Data (.json)]                                  │
│  Generated by AI (ChatGPT / Gemini) using the ZCLE Director Schema.   │
│  Contains scene breakdowns, visual primitives, mathematical           │
│  parameters (radii, depth, colors, angles), and cue_phrase anchors.   │
│                                                                       │
│                                │                                      │
│                                ▼                                      │
│  [ZCLE Auto-Sync Compiler (Python / Manim / FFmpeg)]                  │
│  Matches cue_phrase to audio milliseconds -> compiles Manim script    │
│  with self.play(run_time=...) and self.wait(...) -> 1080p 60fps MP4.  │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

## 4. Key Guarantees
1. **Authentic Visual Primitives:** Modular library (`astrophysics`, `computing`, `neural_ai`, `math_analysis`).
2. **0-Millisecond Drift:** Audio timestamps drive animation run times and wait intervals.

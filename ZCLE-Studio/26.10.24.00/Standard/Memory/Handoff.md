## 1. Quick Orientation for Any New AI Model

If you are a new AI model taking over this project, **READ THIS CAREFULLY**:

1. **User Goal:** The user wants an automated software ("ZCLE Studio") that generates **programmatic 3Blue1Brown-style educational videos** from input data.
2. **What the User Demands:**
   - **No fake static templates:** A Black Hole video must NOT look like a CPU video with swapped text. It must have real spacetime curvature, event horizons, photon spheres.
   - **0-Second Audio Drift:** Audio narration and on-screen visuals must be **100% in lockstep**. When a word is spoken at second `05.20`, that exact animation must trigger at `05.20s` (not 1 second before, not 1 second after).
   - **Data-Driven Geometry:** All graphics (curves, angles, dial needles, probabilities) must be backed by real numerical values.
3. **The 2-File Solution Approved by User:**
   - **File 1 (`narration.txt`):** The human-readable explanation text of the chapter/topic.
   - **File 2 (`director.json`):** A JSON file generated by ChatGPT or Gemini based on the text. It specifies:
     - `cue_phrase`: The exact phrase in the text where this visual action triggers.
     - `visual_primitive`: What Manim object to build (e.g. `spacetime_grid`, `event_horizon`, `silicon_die`, `logic_gates`, `neural_slab_3d`).
     - `action`: The animation to perform (`WARP_CURVATURE`, `SPAWN_SPHERE`, `BEND_LIGHT`).
     - `parameters`: Exact numerical data (mass, radius, depth, color, coordinates).
4. **Where the Code Lives:**
   - Visual Primitives: `Dev/ZCLE_Engine/core/visual_primitives/`
   - Audio Sync & Timestamps: `Dev/ZCLE_Engine/core/audio_sync.py`
   - Dynamic Compiler: `Dev/ZCLE_Engine/core/compiler.py`
   - Web Server: `Dev/ZCLE_Engine/server.py`

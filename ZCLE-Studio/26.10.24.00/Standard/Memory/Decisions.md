## Architecture Decision Records (ADR)

### ADR-001: Adoption of ZOE Standard Folder Structure
- **Date:** 2026-10-24
- **Decision:** ZCLE Studio is organized strictly under `<Project>/<Version>/Standard/` with `Memory/`, `Planning/`, `Research/`, `Docs/`, `Dev/`, and `Assets/`.
- **Rationale:** Guarantees total state retention across agent handoffs and tool sessions.

### ADR-002: Zero-Dependency Browser Player for CPU Pilot
- **Date:** 2026-10-23
- **Decision:** Legacy CPU pilot at `Dev/Studio_App/app/index.html` runs offline via native 2D Canvas + WebGL.

### ADR-003: Edge Neural TTS for Narration
- **Date:** 2026-10-23
- **Decision:** Edge-TTS (`hi-IN-MadhurNeural` for Hinglish, `en-US-ChristopherNeural` for English) is used for studio-grade voiceover.

### ADR-004: Rejection of Fixed Generic Card Templates
- **Date:** 2026-10-24
- **Decision:** Terminated the previous approach of using 5 fixed card templates (`title_intro`, `prob_distribution`, etc.) where only labels changed.
- **Rationale:** 3Blue1Brown-quality explainers require topic-specific scientific geometry (e.g., Spacetime grids for Black Holes, Logic gates for CPUs, 3D dial slabs for LLMs).

### ADR-005: 3Blue1Brown Reference Video Benchmark
- **Date:** 2026-10-24
- **Decision:** Formally benchmarked against Grant Sanderson's `vidssave.com Large Language Models explained briefly 480P.mp4` (Duration: 07:57).
- **Key Findings:** 3b1b achieves 0-drift synchronization by binding speech pause durations and word timings directly to Manim `self.play(run_time=...)` and `self.wait(...)`.

### ADR-006: The 2-File Architecture (Text Script + AI Director JSON)
- **Date:** 2026-10-24
- **Decision:** Approved by user. ZCLE Studio inputs consist of:
  - **File 1:** Explanation Text Script (Narration speech).
  - **File 2:** AI Director JSON (Visual primitives, numerical parameters, and `cue_phrase` speech anchors) generated by ChatGPT or Gemini.
- **Rationale:** Decouples human narration writing from mathematical animation geometry while allowing LLMs to act as visual cinematographers.

### ADR-007: Millisecond Speech-to-Animation Alignment Engine
- **Date:** 2026-10-24
- **Decision:** Edge-TTS sentence boundary events and word-level interpolation provide millisecond timestamps. The ZCLE Compiler matches `cue_phrase` in File 2 with speech timestamps to calculate exact `run_time` and `self.wait()` parameters.

### ADR-008: Modular Mathematical Visual Primitives Library
- **Date:** 2026-10-24
- **Decision:** Visual elements are implemented as reusable Manim classes in `Dev/ZCLE_Engine/core/visual_primitives/`:
  - `astrophysics.py` (SpacetimeCurvatureGrid, EventHorizonSphere, GeodesicPhotonBeam)
  - `computing.py` (SiliconDie, LogicGateCircuit, ClockSquareWave, DataBusPacket)
  - `neural.py` (NeuralSlab3D, TokenVectorColumn, ProbabilityBarChart)
  - `math_analysis.py` (CoordPlane, TangentVector, FunctionGraph)

# Memory — Single Source of Truth (SSOT)

**Directory Role:** Project State, Memory Map, and Context Retention  
**Package:** ZCLE Studio (`26.10.24.00/Standard`)

---

## Purpose of Memory

AI models aur human developers ke switch hote waqt context lose na ho, iske liye yeh directory permanent memory ka kaam karti hai. Isme project ka past, present aur future roadmap clearly documented hai.

## Memory Navigation Map

| File | Content & Purpose |
|---|---|
| [`Vision.md`](./Vision.md) | Kya aur kyun ban raha hai; high-level educational purpose. |
| [`Decisions.md`](./Decisions.md) | Approved technical aur architectural decisions ka record. |
| [`Current-Status.md`](./Current-Status.md) | Project ka live status (Completed features, In-progress, Blockers). |
| [`Next-Tasks.md`](./Next-Tasks.md) | Next actionable priorities in order of execution. |
| [`Handoff.md`](./Handoff.md) | AI model transition guide; context resume karne ka instructions. |
